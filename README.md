# E-Commerce Platform

A full-stack e-commerce platform built as a reusable foundation for
custom online stores.

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript

### Backend
- Node.js
- Express
- Prisma

### Database
- PostgreSQL

## Architecture

Next.js → Express → Prisma → PostgreSQL

## Current Features

- Express REST API
- PostgreSQL database
- Prisma ORM
- Product data model
- Category data model
- Cart data model
- Order data model
- Wishlist data model
- Review data model
- Database migrations
